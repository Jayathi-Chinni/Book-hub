# 📚 Book Hub – Online Book Browsing Application

## 📌 Project Overview

Book Hub is a React-based web application that provides users with an organized platform to explore and discover books. It allows users to browse top-rated books, explore different book shelves, view detailed book information, and manage their reading preferences through a user-friendly interface.

The application uses protected routes and API integration to provide an authenticated book-browsing experience.

## ✨ Features

- **User Authentication:** Secure login functionality with JWT-based authentication.
- **Home Page:** Displays top-rated books for users to explore.
- **Book Shelves:** Browse books based on reading categories.
- **Category Filtering:** Filter books by All, Read, Currently Reading, and Want to Read.
- **Book Details:** View detailed information about individual books.
- **Protected Routes:** Restricts access to application pages based on authentication status.
- **API Integration:** Fetches book information from backend APIs.
- **Error Handling:** Displays appropriate error and fallback pages.
- **Responsive UI:** Provides a user-friendly browsing experience across different screen sizes.

## 🛠️ Technologies Used

- **React.js** – Building reusable UI components.
- **JavaScript (ES6+)** – Implementing application functionality.
- **HTML5** – Structuring application content.
- **CSS3** – Styling and responsive layouts.
- **React Router** – Handling navigation and routing.
- **REST API** – Fetching book data and handling authentication.
- **JWT & js-cookie** – Managing authentication tokens.

## 🧩 Key React Concepts Implemented

- Functional Components
- Props and State Management
- React Hooks (`useState`, `useEffect`)
- Conditional Rendering
- Component-Based Architecture
- Event Handling
- React Router and Protected Routes
- API Requests and Error Handling

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/book-hub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd book-hub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the application in your browser at the local URL displayed in the terminal.
